# Audito company demo checklists

These five checklists are designed for the **Serendib Integrated Manufacturing (Pvt) Ltd** demo organization.

## How to enter them

1. Create the checklist using the metadata at the top of each file.
2. In the organization tree, open the entity shown in the **Entity path** column.
3. Add the question with the specified answer type.
4. For non-free-text questions, add the listed options and marks. The option marks for every question total exactly 10, as required by Audito.
5. Entity codes and organization-tree IDs are generated by the live system; do not copy or invent them from these files.

## Supported answer types used

- `Single Option`: one answer, normally Yes (10) or No (0).
- `Drop Down`: Fully compliant (7), Partially compliant (3), or Non-compliant (0).
- `Multiple Options`: five independently selectable controls worth 2 marks each.
- `Free Text`: narrative response with no configured options.

## Functions covered by the demo set

- Questions on Company, Cluster, Factory, Unit, Department, and Section nodes.
- All four checklist answer types.
- Multiple sibling entities and deep organization-tree paths.
- Scoring, question counts, audit progress, remarks, evidence uploads, failed responses, corrective-action requirements, CAP views, overdue audits, and completion.

Evidence, remarks, and corrective-action requirements are selected while executing an audit, not while creating a checklist. Each checklist therefore includes a short **Demo execution scenario** identifying responses to use for those tests.
